# CACE characterization: d2s_miller (draft)

Characterizes the Miller-compensated class-AB pad driver of `../../class_ab_pad_driver.md`.
The setup follows the OgueyAebischerBias deck: one `.yaml`, one xschem template for each
kind of analysis, and a wrapper cell as the DUT.

Generated by `../../gen_cace_templates.py`; edit the generator, not the `.sch`:

- `templates/*.sch`
- `../../xschem/d2s_miller_biased.{sch,sym}`

```
cd verification/cace
cace d2s_miller_biased.yaml -s schematic            # everything (~350 runs)
cace d2s_miller_biased.yaml -s schematic -p dc_params loop_params
```

## DUT and fixture

| cell | role |
|---|---|
| `d2s_miller` | the amplifier, hand-drawn, unchanged |
| `d2s_bias` | test fixture: six ideal reference currents into diode replicas |
| `d2s_miller_biased` | CACE DUT = `d2s_miller` + `d2s_bias`, same 13 pins as `d2s_miller`; the bias nets are pins so the templates can perturb them |

Why a wrapper: CACE turns only the DUT symbol into a primitive. Any other subcircuit symbol in a
template must be found by xschem, and the PDK `xschemrc` resets `XSCHEM_LIBRARY_PATH`. This is
the same arrangement as `reference.sch` = `OgueyAebischerBias` + `ToBiasStartup`.

## Conditions

| condition | typical | swept in | meaning |
|---|---|---|---|
| vdd | 3.3 V | dc, dc_bias | 3.0 / 3.6 |
| corner_mos | tt | dc, loop, ac, tran, noise, drive | ss sf tt fs ff |
| corner_r | typ | dc | bcs typ wcs (rhigh degeneration sets the gain) |
| corner_c | typ | loop_bias | bcs typ wcs (MOM Miller caps) |
| temp | 27 °C | dc, loop | −40 / 125 |
| rload, vterm | 1 kΩ to 1.65 V | dc_load, loop_load, drive | 50 Ω … open; vterm = 0 is the sourcing-only case |
| cload | 100 pF | loop_load | 10 p … 1 nF |
| ibias_err | 0 % | dc_bias, loop_bias | common error of all six reference currents, ±40 % (the Oguey reference spread about that much in its first CACE run) |
| va_bias | 1e12 V | dc_bias | "Early voltage" of the reference sources: R_k = va_bias / I_k across each source, returned to its far rail |
| vicm, vref | 1.65 V | (not yet) | input common mode, output reference |
| vstep, vdamp, fin, vdmax, vdbig | per group | tran, thd, dc, drive | stimulus |

The bias-quality knobs sit in the template as `IQ*` / `RQ*` elements below the ground bus: an
extra `ibias_err·I_k` source and `va_bias/I_k` resistor across each reference.

## Parameter groups

| group | template | quantities |
|---|---|---|
| dc_params, dc_bias_params, dc_load_params | `_tb_dc` | Gain, Vos_out, INL (±1 V vd), Idd, IqP, IqN, Imin |
| loop_params, loop_load_params, loop_bias_params | `_tb_loop` | T0, fc, PM, GM (loop broken at the vfb gate, DC closed through 1 GH) |
| ac_params | `_tb_ac` | Acl at 1 kHz, f3dB, PSRR 1 k / 100 k (output-referred), CMRR 1 k, Zout 1 k / 1 M |
| tran_params | `_tb_tran` | SR rise/fall (10–90 %), overshoot, 1 % settling rise/fall |
| thd_params | `_tb_thd` | THD h2…h7 (root-sum-square, 4 periods × 1024 points, rectangular window), output amplitude |
| noise_params | `_tb_noise` | output noise at 1 k / 100 k, integrated 10 Hz–10 MHz |
| drive_params | `_tb_drive` | Vout max/min into load at full overdrive, short-circuit current source/sink |
| mm_params, mc_params | `_tb_dc` | histograms of Vos_out, Gain, IqP (mismatch: tt_mismatch; process: tt_stat) |

Spec limits are proposals around the tt numbers of `../../results.txt`, not requirements.

## Template conventions (learned the hard way)

- **Data file name is relative** (`echo … > CACE{filename}_CACE{N}.data`), because CACE runs
  ngspice in the run directory. With `CACE{simpath}/…` the line got long enough for xschem to
  wrap it with a `+` continuation, and ngspice does not join those inside `.control`.
- **`CACE{simpath}` still appears once, in a schematic text.** CACE's plotting code expects
  `simpath` in every condition set, and it only lands there if the template mentions it.
- **Scalars across analyses go through `set s_x = $&x`.** A `let` scalar lives in its own plot
  and is gone after the next `ac` or `noise`.
- **`.noise` needs `sparse`** instead of `klu`, as in the Oguey noise template.
- **Slow parallel runs:** if they are much slower than one run alone, set
  `export OMP_WAIT_POLICY=passive OMP_NUM_THREADS=1`. With 2 cores and `-j 2`, a 0.4 s
  simulation took 60 s because ngspice's OpenMP threads were spin-waiting.

## Moving into sg13cmos5l_IOPadDiff2Single (later)

- In the yaml, change `paths.schematic` to `../schematic/xschem`.
- The DUT becomes the pad-level cell.
- `d2s_bias` (ideal currents) gets replaced by the real bias distribution from one ibias
  input. Then `ibias_err` / `va_bias` act on that single input instead of six references.
