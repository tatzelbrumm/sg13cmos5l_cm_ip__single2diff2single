JanteStroemSpejl — clean Xschem rebuild
=======================================

This directory was generated from scratch.  It does not reuse the earlier
CACE package or the earlier generated Xschem files.

Files:
  JanteStroemSpejl.sch
  JanteStroemSpejl.sym
  JanteStroemSpejl_tb_mismatch.sch
  EXPECTED_DUT_NETLIST.txt

DUT:
  22 explicit sg13_lv_nmos instances.
  No multiplicity/finger abstraction: m=1, ng=1 everywhere.
  mm_ok=1 everywhere.
  Row 6 is the diode-connected reference pair.
  Rows 1-5,7-11 form OUT01..OUT10.
  WJ=4 lambda, LJ=64 lambda, lambda=0.08 um.

Important Xschem construction detail:
  net labels are placed directly on the verified sg13_lv_nmos pin centers:
      D=(x+20,y-30), G=(x-20,y), S=(x+20,y+30), B=(x+20,y)
  No label stubs are used.

Standalone mismatch testbench:
  IREF=100 uA.
  S=B=0.
  Each OUTxx is clamped to V(IREF) through a unity-gain VCVS.
  VMONxx senses the output current.
  mos_tt_mismatch is selected.
  500 reset/op iterations are written to JanteStroemSpejl_mismatch.dat.

Before trusting a run, compare the generated DUT portion against
EXPECTED_DUT_NETLIST.txt.  In particular, there must be no autogenerated
net1...net22 on DUT transistor terminals.
