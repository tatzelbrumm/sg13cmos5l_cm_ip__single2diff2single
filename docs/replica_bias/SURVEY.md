# Replica bias for vref / vcm of the custom pads: Phase 1 survey

Read-only survey, 2026-11-06 (task file `docs/launch/replica_bias_TASK.md` on branch `harness-test`). No new simulation was
run. Every number below comes from committed results:
- CACE CSVs of the pads on `claude/c4-replica-bias` = `origin/toplevel` `cf88683`;
- design notes and logs on `claude/c4-replica-bias-sudel` = `origin/sudel_buecher` `aecf1bb`.

The tables are regenerated by `sudelbuecher/design_considerations/replica_bias/phase1/survey_tables.py` (notes branch).
Its output is `sudelbuecher/logs/replica-bias/phase1_survey_tables.log`. Commands: `RUNLOG.md`.

**Criterion used for the bands.** The S2D INL limit, ≤ 2 mV over a ±0.5 V signal on the unit gates:
- S2D: u = pad − vref = ±0.5 V, so `vfbp/vfbn = vcm ± 0.5 V`;
- D2S: vd = ±1 V, so `vinp/vinn = vicm ± 0.5 V` and `pad = vref ± 0.5 V`.

A smaller signal widens every band by the same amount. The D2S INL limit (10 mV, iovdd ≥ 3.3 V only) is looser.
Using 2 mV for both is the conservative reading. Statements marked *(inferred)* are my reading of the data; no run has
shown them directly.

## 1. Where the three voltages go (netlists)

| net | gates it drives | other loads | source today |
|---|---|---|---|
| S2D `vref` (pad reference) | `s2d_mpdda`: gn of A1, A2 (input units, opposite the pad) | none | CACE: ideal 1.2 V (`window_params` 0.5 V); slot fallback: harness `vbias` |
| S2D `vcm` (output common mode) | `s2d_mpdda`: gp of F1, gn of F2 (feedback units), gn of M1, M2 (CMFB units) | `s2d_mpdda_pd`: TPN / TPP / TNN / TNP tie `outp` / `outn` to `vcm` while disabled | CACE: ideal 1.2 V; slot fallback: `vbias` |
| D2S `vref` (output reference) | `d2s_mpdda_pd`: gn of A, gp of B, gp of C1, C2 (every unit has vref on one gate) | none | CACE: ideal 1.65 V; slot fallback: `vbias` |
| D2S input common mode `(vinp + vinn)/2` | gp of A, gn of B (opposite vref) | — | in the chain: the S2D outputs, CM = S2D `vcm` + its CM error (5…18 mV, σ 12 mV under mismatch) |

What else depends on the D2S input common mode:
- The matched-pair balance of `d2s_mpdda` assumes `vicm = vref`. An input CM error c makes the input units carry
  f(u + c) + f(u − c), an error second order in c (`class_ab_pad_driver/improvements/proposed_improvements.md` §II).
- So D2S `vref` must equal D2S `vicm`, which in the chain is S2D `vcm` (`s2d_input_buffer.md` §IV: "a decision for
  both buffers").
- **The S2D `vcm` and the D2S `vref` therefore have one target, and can come from one block.**

- **Top edge.** The highest unit gate (vcm + 0.5 V) may reach:
  - iovdd − 1.245 V (3.0 V) and iovdd − 1.270 V (3.3 V) at ss / −40 °C;
  - iovdd − 1.15 … 1.18 V at tt / fs 27 °C;

  - −0.12 V to the bottom (at ss / 125 °C).

**Replica candidates.**
- **Top edge:** a copy of one unit half, tail at vbp plus input follower, fed from the same tree. It tracks iovdd, the
  PMOS corner, temperature and the reference current together.
- **Bottom of vcm:** a copy of the S2D NMOS fold (BN / BNC diodes, CX copy).
- **The vcm block** would combine the two, for example the centre of the two edges. With a top-edge replica alone,
  vcm would follow iovdd at about 0.9 V/V, and with it the D2S output DC level.
- Of all the bias lines, only nominal values are on record (vbp 1.972 V, vbn 0.914 V at tt, 3.3 V; D2S `tb_pad_dc`).

## 6. Contradictions between sources

1. **1.2 V against 1.65 V.**
   - 1.2 V: the S2D yaml, the S2D README, `s2d_input_buffer.md` §IV, §VII.
   - 1.65 V: the D2S yaml (vref = vicm = vterm = 1.65 V), the D2S README, every S2D design deck and every D2S deck.
   - The D2S README ("Not done") and `FILL_IN.md` item 2 already flag this. The D2S data at 1.65 V show the
     predicted top-edge failure. Nobody has run the D2S at 1.2 V.
2. **S2D `vref` default 1.2 V against the requirement that the pad range include vssio.**
   - 1.2 V: the yaml, `tb_pad_dc`, the slot fallback with vref = vcm = `vbias`. At 1.2 V the pad range is
     0.48 … 1.94 V at tt.
   - 0.5 V: `window_params`, `s2d_input_buffer.md` IX.2, `FILL_IN.md` item 3.
3. **The rule "unit gates ≤ about iovdd − 1.3 V" against the data.** The 2 mV edge is at iovdd − 1.25…1.27 V at
   ss / −40 °C, iovdd − 1.15…1.18 V at tt / fs 27 °C and iovdd − 1.0 V at ff / 125 °C. The rule is the rounded worst
   case, not a constant. That PVT dependence is what a replica can follow.
4. **An undocumented bottom edge of vcm.** At 1.07–1.08 V (ss / 125 °C), independent of iovdd. §IV gives only the top
   edge for vcm and "vin ≥ 0 V" for the input. With vcm = 1.2 V, the margin to it (0.12 V) is wider than to the top at
   3.0 V (0.055 V).
5. **Stale port descriptions.**
   - The D2S README's port table (ibias, en_1v2, sel*, sense) and the slot README's core-side pin table predate the
     2026-11-03/04 partition (ports `iref`, `en_3v3`, `en_3v3_b`).
   - `FILL_IN.md` items 1 and 5 still describe `bias_sel_pd` as the pad's bias.

   Not a target question, but it is where a replica block's enable and current would come from.
6. **CACE version.** The S2D README names CACE 2.13.0 for the 2026-10-25/26 runs; this container has CACE 2.11.0
   (`RUNLOG.md`).

## 7. Power-down: what the pads expect

- **S2D disabled:** `outp` and `outn` are tied to `vcm` by TGs, so "the next stage sees a zero differential input at
  the internal common mode" (`s2d_pd.spice`; `s2d_d2s_pinbuffers.md`: "inbuf_en … input of next internal stage to VCM
  if off").
  - So `vcm` must stay valid while S2D is off and the next stage runs. **The vcm block cannot share the S2D enable.** It
    needs its own enable, or the OR of its consumers' enables.
  - When it is off, everything it feeds is off too. It can then pull vcm to iovss: gates and TG junctions only.
- **D2S disabled:** the front end and the output devices are off. `vref` sees gates only, so any level is safe;
  `tb_pd_unpowered` holds it at 0 V.
- **S2D `vref`:** gates only. Pulled to iovss when off.
- **Rail.** The top edge is referenced to the units' rail. In the custom-pad route that is iovdd (the ring); in the
  slot fallback, vdd_3v3. A replica that tracks the top edge has to sit on the same rail, fed by a current leg (bias
  crosses between blocks only as current, `bias.md`). That means in or next to the pad cell, not on a different
  supply.
