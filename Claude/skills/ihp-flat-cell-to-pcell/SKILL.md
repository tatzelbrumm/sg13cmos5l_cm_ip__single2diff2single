# Flattened IHP cells -> parametrized PyCells

Worked example: `sg13cmos5l_cm_ip__single2diff2single/scripts/pcells` (Clamp_N / Clamp_P from `sg13cmos5l_io`). Reuse its file layout and scripts as the template.

## 0. Environment (cloud container, no PDK install)
- `pip install --break-system-packages klayout` gives klayout.db 0.30.x in Python (also provides `pya`). It has no DRC/LVS DSL.
- Sparse-clone `IHP-GmbH/ihp-sg13cmos5l` with `libs.tech/klayout/{python,tech}`. Many files there are **symlinks into `../ihp-sg13g2/...`**: also sparse-clone `IHP-GmbH/IHP-Open-PDK` and symlink `ihp-sg13g2` as a sibling of the cmos5l checkout.
- The submodules `pycell4klayout-api` and `pypreprocessor` are empty. Clone both into `ihp-sg13g2/libs.tech/klayout/python/`.
- To run the PDK PCells standalone, put `libs.tech/klayout/python` and `.../pycell4klayout-api/source/python` on `sys.path`, then `import sg13cmos5l_pycell_lib`. Look the library up with `pya.Library.library_by_name('SG13_dev', SG13_Tech.TECH_NAME)`: the technology name is required. Set `layout.technology_name` before calling `create_cell(pcell, lib, params)`.
- Layer names come from the `.lyp` (`Name.purpose` -> gds l/d); cni `Layer(name, purpose)` uses the same keys.
- Connected-folder repos: **no git commands** (index.lock trap). Read files with device_bash; stage big binaries only when needed; write results with `device_commit_files` and checksum them afterwards.

## 1. Analyse
- Library cells aren't top cells (`is_top()` is False); select them by name.
- Per cell and layer, dump merged polygons and bboxes. Summarise small squares (contacts 0.16 µm, vias 0.19 µm) as columns with pitch rather than listing them.
- Compute per layer the **intersection across all references** of a family and variant, and the residual per cell. That shows the fixed frame, the scaling part and any hand-placed part.
- Render PNGs with matplotlib to look at the cells, and check the CDL subckts for W/ng/diode/resistor values.
- Expect hand-drawn irregularities (extra overlapping shapes, odd via pitch in one cell, labels at random y). Don't try to derive rules for those.

## 2. Decompose: frame / rule array / tie template
- **Rule part.** Everything periodic. Find closed forms, e.g. active length = a + b·ng valid for both parities, centred on a fixed x. Keep all coordinates as integer nm on the 5 nm grid.
- **Frame.** Intersection over refs of (ref − generated), stored as extracted geometry. Use the `esd_code.py` convention: boxes, simple polygons, and `(x0,y0,w,h,nx,ny,px,py)` arrays for contacts.
- **Tie/hand block.** ref − frame − generated. **Assert** that it lies inside a window around an anchor (e.g. the M2 strap x), otherwise the rules are wrong. Store it relative to the anchor. Interpolate the anchor piecewise-linearly in the parameter and snap to the grid. Take the block itself from the nearest reference (ties go to the larger one).
- Also assert that the rules generate nothing absent from the reference.
- **Subsumed layers.** If an array shape lies inside a bigger frame shape on the same layer (P-array NWell inside the frame NWell), subtracting it punches a hole. Detect this by the hole count going up and skip the subtraction for that layer.
- Pins and texts go in their own classes: in-window ones join the tie template; ring labels are per-ref decor; repetitive labels ('pad') are regenerated by rule and only their coverage is verified.

## 3. Code structure (IHP conventions)
- `<name>_code.py` with `class <name>(DloGen)`: `defineParamSpecs(cls, specs)` (with `cdf_version`, `Display`, `model` plus your params; `ChoiceConstraint`), `setupParams`, `genLayout`. Share code through a `*_base_code.py` base class, like `rfmosfet_base_code.py`.
- Emit shapes with `dbCreateRect(self, Layer(l,p), Box(µm...))`, `dbCreatePolygon(..., PointList([Point()]))` and `dbCreateLabel(self, layer, Point, text, 'centerCenter', 'R0', Font.EURO_STYLE, size)`.
- Register in `__init__.py` like `PyCellLib`: import `sg13cmos5l_pycell_lib` first (it creates the SG13_dev tech), then `register_pcell(name, PCellWrapper(cls(), Tech.get('SG13_dev'), None, path))` and `lib.register('<LIB>')`.
- Keep the geometry in a **pure-Python engine** (no klayout import) so the PCell, the batch CLI and the verifier share it. Write a generated `*_refdata.py` with an extractor script that records the source sha256.
- Loader: import the directory as a uniquely named package via `importlib.util.spec_from_file_location(..., submodule_search_locations=[dir])`. `exec(open(...))` breaks `__file__`; use `klayout -rm` or `runpy.run_path`.

## 4. Verify
1. **XOR**: merge each layer and compare generated vs reference for every reference, through both the engine and the real cni PCell path (instantiate, flatten, compare). Target: empty on all drawing and pin layers.
2. **Sweep** every legal parameter value. Check gate count and strap count; enforce clearance limits (array vs tie block ≥ 2 µm, array and tie block inside the guard ring).
3. **DRC**. The IHP deck needs KLayout ≥ 0.29.11 and apt only has 0.28.16. klayout.org and conda are unreachable, and building from source on 2 cores is too slow. Instead copy the drc dir with `cp -rL` and insert `def absolute; nil; end` after the `layers_def` include. Run `klayout -b -r ihp-sg13cmos5l.drc -rd input=... -rd topcell=... -rd report=... -rd run_mode=flat -rd drc_json=... -rd drc_json_default=... -rd density=false -rd no_angle=true ...` (the angle table gives false hits under the shim). Baseline the references first (expect 0), then DRC every swept cell. Count items per category from the lyrdb.
4. **Connectivity**. The PDK LVS needs ≥ 0.30.2 plus custom extractors. Use `klayout.db.LayoutToNetlist` in Python: `make_polygon_layer` / `make_text_layer`, derived layers `register`ed, `DeviceExtractorMOS3Transistor` (SD = active − poly, G = poly∩active by implant/well), `DeviceExtractorResistor` (rppd body = **PolyRes** region; GatPoly only at the heads). Call `connect(x)` on **every** conductor including cont and vias, then `join_net_names('pad')` (drain straps are joined only by the bond pad above), `extract_netlist()`, `combine_devices()`. Check W, L and net names. Prove the check with injected opens and shorts.
5. **Netlists**: CDL copied from the PDK `.cdl` style; ngspice following the xschem symbol `format=` strings (X-prefixed hv mos, dantenna, ptap1 with `R=` from A and P, rppd with a body pin). Emit `.global sub!`.

## 5. Deliver
Copy only the source files (no `__pycache__`) to `/mnt/user-data/outputs/<dir>`, `device_commit_files` them to the repo, and compare sha256 on both sides. The README should list the decomposition, the verification status with caveats (the DRC shim, that the light LVS isn't sign-off, what is extrapolated), and the exact re-run commands for the IIC-OSIC-TOOLS container.
